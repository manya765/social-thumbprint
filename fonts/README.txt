Recoleta is a commercial font and is not bundled with this project.

To enable it, purchase/license Recoleta and drop the following files into this
folder (exact filenames expected by index.html's @font-face rules):

  Recoleta-Regular.woff2
  Recoleta-Medium.woff2
  Recoleta-SemiBold.woff2
  Recoleta-Bold.woff2

Until these files are present, headings will automatically fall back to
"Fraunces" (loaded from Google Fonts) as configured in the @font-face
`src` fallback chain in index.html.
